# UGC NET Public Administration Study App

## About
A personal study project designed to help me prepare for UGC NET Paper 2 in Public Administration.

## Goals
- Study the complete syllabus topic by topic
- Practise previous year questions (PYQs)
- Analyse question patterns and important topics
- Revise using flashcards and memory techniques
- Learn through simple explanations and real-life examples
- Explore mind maps for connected concepts

## Current Stage
Beginner project — planning and learning GitHub.

## Future Features
- Topic-wise question practice
- Explanations for every answer
- Revision progress tracking
- Mock tests and performance analysis
- Topic-wise notes and mind maps

## Learning Journey
I am building this project step by step while learning how to develop an app.
