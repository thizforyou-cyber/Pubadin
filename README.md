# Pubadin — UGC NET Public Administration Study App

Pubadin is a browser-based study space for UGC NET/JRF Public Administration (Paper 2, subject code 14).

## Features
- **Thinker Time Machine:** chronological thinker catalogue spanning ancient foundations, classical administration, scientific management, human relations, behavioural theory, systems/ecological approaches, policy, public choice, NPM, governance, digital-era governance and Indian administrative thought.
- **Three thinker views:** chronology, schools of thought, and connections between thinkers.
- **Thinker profiles:** key works, contributions, concepts, related thinkers, and criticism / exam nuance.
- Full syllabus topic map, topic notes, starter practice quiz, revision cards, mind maps, progress tracking and browser-based backup export.

## Run locally
This is a static website; no build step or package installation is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Study progress is saved in that browser's local storage.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to finish publishing and use the URL shown in the Pages settings.

## Content and accuracy
The thinker database is an expandable study aid, not an official exhaustive NTA list. Some dates are approximate or refer to a major work rather than the person's lifetime. A thinker may belong to multiple schools. “Core” labels are study-navigation hints, not an official exam-weightage prediction. Verify exact publication details and current syllabus coverage against reliable editions and the official NTA/UGC materials. Practice questions should be labelled as PYQs only after their paper/session and answer key have been verified.
